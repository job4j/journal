# Journal

## Смысл проекта

Journal — электронный журнал для семейных классов.

Проект помогает учителям вести уроки, домашние задания, оценки,
комментарии и учебные материалы. Родители получают персональный доступ
к информации только о своих детях.

Система рассчитана на многолетнее использование. Переход в новый
учебный год или следующий класс не должен требовать копирования проекта,
изменения кода или создания отдельной системы.

## Пользователи

В системе предусмотрены три основные роли:

- Администратор управляет учебными годами, классами, учениками,
  родителями, учителями и предметами.
- Учитель создаёт уроки, указывает темы и домашние задания,
  прикрепляет материалы, создаёт проверочные работы и выставляет оценки.
- Родитель видит расписание, задания, оценки и комментарии только
  для своих детей.

В будущем могут появиться роли ученика и руководителя центра.

## Основные сущности

- Учебный год
- Класс или учебная группа
- Ученик
- Родитель
- Учитель
- Предмет
- Зачисление ученика в класс
- Назначение учителя на предмет
- Урок
- Тема урока
- Домашнее задание
- Учебный материал
- Проверочная работа
- Оценка
- Комментарий учителя
- Пропуск занятия

## Принципы предметной области

- История обучения и оценок должна сохраняться по учебным годам.
- Ученик может переходить между классами и группами.
- В семье может быть несколько детей.
- У ребёнка может быть несколько родителей или представителей.
- Учитель может вести несколько предметов и классов.
- На одном уроке может не быть оценивания или может быть несколько работ.
- Работа имеет тип: домашняя, на уроке, проверка знаний или другой тип.
- Система не должна быть жёстко привязана только к пятибалльной шкале.
- Материалы в первой версии хранятся в виде внешних ссылок.
- Родитель не должен получать данные других семей.

## MVP

Первая версия должна поддерживать:

- авторизацию;
- роли администратора, учителя и родителя;
- учебные годы и классы;
- учеников и связь с родителями;
- учителей и предметы;
- создание уроков;
- темы уроков и домашние задания;
- ссылки на учебные материалы;
- создание оцениваемых работ;
- оценки и комментарии;
- пропуски занятий;
- журнал учителя;
- персональный журнал ребёнка;
- просмотр истории по учебным годам.

## Не входит в первый MVP

- мобильное приложение;
- собственное файловое хранилище;
- видеоконференции;
- Telegram-бот;
- автоматическая генерация оценок;
- сложная аналитика;
- интеграции с государственными образовательными системами.
